Despesas

💾 Os seus dados

Tudo o que escreve fica guardado dentro do navegador deste telemóvel (não vai para a internet nem para o GitHub). Por isso:

  • Adicione o site ao ecrã principal (Safari → Partilhar → Adicionar ao ecrã principal) e abra-o sempre por esse ícone.
  • Não apague os dados de navegação do Safari.
  • Guarde uma cópia regularmente (ex: no fim de cada semana) para o iCloud Drive ou envie por email para si.
